# Design history

Standalone HTML mockups from the portfolio redesign (September 2026), kept as
the revision record. Each file is self-contained: open it directly in a browser.

- `v10-*` — seven competing single-section explorations (bento, chapters, drift,
  logbook, signal, status, topology)
- `v11-mix.html` — mixed-module composition experiment
- `v12-flow.html` — single-column flow experiment
- `v13-alive.html` — motion-first pass
- `v14-lab.html` — lab-figure-focused pass
- `v15-flags.html` — variant flags experiment
- `v16.html` — consolidated single-page direction
- `v17.html` — tightened hero, accessibility and reduced-motion audit, OG card
- `v18.html` — final approved direction: full infrastructure figure, decision-log
  systems rows, Hialeah FL title line

The production site in `src/` is the React/Vite implementation of the v18
direction. These files are history, not source material.
